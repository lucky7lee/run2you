## 🎮 주요 특징
- **스마트폰 가로 화면 전용 최적화**: 양손 엄지 터치 컨트롤 및 세로 회전 잠금 시 강제 가로 모드 지원
- **총 50단계(15분 완주) & 일반 → 고수 → 달인 승급 챌린지**:
  - **일반 단계**: 1~50레벨을 죽지 않고 달리면 총 15분(단계당 18초)이 소요되며, 50레벨 돌파 시 축하 폭죽 이벤트와 함께 **"고수" 단계 진출 버튼** 활성화
  - **🔥 고수 단계**: 다시 1~50레벨까지 15분 간격으로 진행되며 **장애물 수가 일반 대비 1.5배**로 증가! 50레벨 돌파 시 축하 이벤트와 함께 **"달인" 단계 진출 버튼** 활성화
  - **👑 달인 단계**: 다시 1~50레벨까지 15분 간격으로 진행되며 **장애물 수가 고수 단계 대비 1.5배(일반 대비 2.25배)**로 증가하는 최종 마스터 코스
- **다채로운 도로 굴곡 & 초대형 높은 언덕**: 완만한 웨이브뿐만 아니라 **초대형 급경사 대언덕(Mega Peaks)**, 낙타봉 이중 능선, 고원 절벽 단차, 롤러코스터 급강하 등 다이나믹한 선 도로 지형
- **✈️ 비행기 변신 아이템 (15분간 랜덤 5회 등장 · 7초 무적 자동 비행)**:
  - 황금빛 **`✈️ 비행기 변신 (7초 무적)`** 캡슐 획득 시 오토바이가 즉시 초음속 제트 비행기로 변신하여 **별도 컨트롤 없이 7초간 무적 상태로 자동 비행**하며 모든 장애물을 격파!
- **복합 결합 장애물(2~3연속) & 높낮이별 공중 장애물**:
  - **지상 장애물 (10종 + 2~3연속 결합)**: 단독 등장뿐만 아니라 **2개 또는 3개가 동시에 붙어서 등장**하며, 장애물 길이에 맞춰 **짧은 점프** 또는 **긴 점프**로 도약
  - **낮은 공중 장애물**: 점프하지 않고 밑으로 그냥 지나가도 되고, 점프해서 위로 아예 뛰어넘어도 통과 가능
  - **초고층 공중 장애물**: 하늘 높이 솟아 있어서 **그냥 지나가야 살고, 점프하면 높게 솟은 장애물 벽에 부딪혀 사망**
- **🎁 무기 보급 시스템 (시작 시 총알 9발 · 바주카포 1발 / 10% 희귀 보급)**:
  - ⚡ **총알 (FIRE)**: 보급 상자 획득 시 **+5발** 충전, **3발 명중 시 장애물 파괴**
  - 🚀 **바주카포 (BAZOOKA)**: 보급 상자 획득 시 **+1발** 충전, **단 1발에 모든 장애물 즉시 폭파**
- **최고 기록 갱신**: 실시간 주행 거리(`m`) 표시 및 이전 최고 기록(`BEST RECORD`) 지점 네온 폴대 표시
