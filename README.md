# 🏍️ RUN 2 YOU - Neon Line Bike Runner

스마트폰 전용 2D 횡스크롤 네온 라인 오토바이 액션 러너 게임입니다.

- **GitHub 저장소 링크**: https://github.com/lucky7lee/run2you

## 🎮 주요 특징
- **스마트폰 가로 화면 전용 최적화**: 양손 엄지 터치 컨트롤 및 세로 회전 잠금 시 강제 가로 모드 지원
- **총 50단계(약 20분 완주) 구성**: 각 단계당 24초 분량의 도로 길이로 정교하게 설계되어, 죽지 않고 50단계 최종 스테이지까지 완주 시 약 20분이 소요되는 챌린지 구조
- **다채로운 도로 굴곡 & 초대형 높은 언덕**: 완만한 웨이브뿐만 아니라 **초대형 급경사 대언덕(Mega Peaks)**, 낙타봉 이중 능선, 고원 절벽 단차, 롤러코스터 급강하 등 다이나믹한 선 도로 지형
- **✈️ 비행기 변신 아이템 (20분간 랜덤 5회 등장 · 10초 무적 자동 비행)**:
  - 황금빛 **`✈️ 비행기 변신`** 보급 캡슐 획득 시 오토바이가 즉시 초음속 제트 비행기로 변신하여 **별도 컨트롤 없이 10초간 무적 상태로 자동 비행**하며 모든 장애물을 격파!
- **복합 결합 장애물(2~3연속) & 공중(점프 금지) 장애물**:
  - ⚠ **지상 위험 장애물 (10종 + 2~3연속 결합)**: 단독 등장뿐만 아니라 **2개 또는 3개가 동시에 붙어서 등장**하며, 장애물 길이에 맞춰 **짧은 점프** 또는 **긴 점프**로 도약
  - ⬇ **땅 위(공중) 장애물 (점프 금지 · 그냥 통과)**: 도로 위 허공에 떠 있는 드론·회전톱날·고압 전기장으로, **점프하면 충돌해 사망하고 점프하지 않고 그냥 달려야 밑으로 안전하게 통과**되는 전략적 장애물
  - 🎁 **무기 보급 캡슐 (총알/바주카포)**: 초록/시안 후광 빛기둥과 낙하산 홀로그램이 달린 공중 보급 상자로 장애물과 한눈에 구분!
    - ⚡ **총알 (FIRE)**: **3발 명중 시 장애물 파괴**
    - 🚀 **바주카포 (BAZOOKA)**: **단 1발에 모든 장애물 즉시 폭파**
- **최고 기록 갱신**: 실시간 주행 거리(`m`) 표시 및 이전 최고 기록(`BEST RECORD`) 지점 네온 폴대 표시
