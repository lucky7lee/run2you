# 🏍️ RUN 2 YOU - Neon Line Bike Runner

스마트폰 전용 2D 횡스크롤 네온 라인 오토바이 액션 러너 게임입니다.

## 🎮 주요 특징
- **스마트폰 가로 화면 전용 최적화**: 양손 엄지 터치 컨트롤 및 세로 회전 잠금 시 강제 가로 모드 지원
- **길이별 맞춤 점프**: 장애물의 길이에 따라 **짧게 터치(단거리 점프)** 또는 **길게 홀드(장거리 점프)**하여 도약
- **무기 시스템**:
  - ⚡ **총알 (FIRE)**: 도로 위 총알 아이템 획득, **3발 명중 시 장애물 파괴**
  - 🚀 **바주카포 (BAZOOKA)**: 바주카 아이템 획득, **단 1발에 모든 장애물 즉시 폭파**
- **5가지 네온 도로 테마 & 단계별 난이도**: 달린 거리에 따라 변화하는 선 도로와 속도에 맞춘 5종의 장애물 등장
- **최고 기록 갱신**: 실시간 주행 거리(`m`) 표시 및 이전 최고 기록(`BEST RECORD`) 지점 네온 폴대 표시
