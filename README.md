스마트폰 전용 2D 횡스크롤 네온 라인 오토바이 액션 러너 게임입니다.

## 🎮 주요 특징
- **스마트폰 가로 화면 전용 최적화**: 양손 엄지 터치 컨트롤 및 세로 회전 잠금 시 강제 가로 모드 지원
- **총 50단계(약 30분 완주) 구성**: 레벨별 도로 길이와 속도가 정교하게 설계되어, 죽지 않고 50단계 최종 스테이지까지 완주 시 약 30분이 소요되는 챌린지 구조
- **길이별 맞춤 점프**: 아담하고 날렵한 네온 바이크로 장애물의 길이에 따라 **짧게 터치(단거리 점프)** 또는 **길게 홀드(장거리 점프)**하여 도약
- **10종의 다양한 위험 장애물 vs 홀로그램 보급 상자**:
  - ⚠ **위험 장애물 (10종)**: 붉은색 경고 테마 + 바닥 노란/검정 위험 빗금 받침대 (삼각 가시, 회전 원형 톱날, 고압 레이저 허들, 강철 바리케이드, 플라즈마 화염 분출기, 장거리 가시 지대, 블러드 크리스탈 암석군, 테슬라 고압 타워, 보초 스파이더 포탑, 초장거리 중장갑 벙커)
  - 🎁 **무기 보급 캡슐 (총알/바주카포)**: 초록/시안 후광 빛기둥과 낙하산 홀로그램이 달린 공중 보급 상자로 장애물과 한눈에 구분!
    - ⚡ **총알 (FIRE)**: **3발 명중 시 장애물 파괴**
    - 🚀 **바주카포 (BAZOOKA)**: **단 1발에 모든 장애물 즉시 폭파**
- **최고 기록 갱신**: 실시간 주행 거리(`m`) 표시 및 이전 최고 기록(`BEST RECORD`) 지점 네온 폴대 표시
